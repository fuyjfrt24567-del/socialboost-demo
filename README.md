# SocialBoost Demo

Website demo phục vụ đồ án, mô phỏng một social media service panel.

## Cách chạy bằng VS Code

1. Cài Node.js nếu máy chưa có.
2. Mở thư mục `socialboost-demo` bằng VS Code.
3. Mở Terminal trong VS Code.
4. Chạy:

```bash
npm install
npm start
```

5. Mở trình duyệt vào:

http://localhost:3000

## Chức năng hiện có

- Trang chủ dashboard
- Danh mục TikTok / Facebook / Instagram / YouTube
- Tìm kiếm và lọc dịch vụ
- Tạo đơn demo
- Tự tính tiền
- Xem lịch sử đơn hàng
- Responsive cho điện thoại

## Lưu ý

Dữ liệu hiện lưu tạm trong RAM. Khi tắt server, đơn mới sẽ mất. Bản nâng cấp có thể kết nối MySQL/SQL Server và thêm đăng nhập, đăng ký, admin, nạp tiền giả lập.
